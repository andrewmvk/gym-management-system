# Traceability Matrix

Unit 2 §7: the matrix links **requirement to prompt to generated artifact to test/evidence**. There is one row per prompt, in dependency order. Artifacts and evidence start as the expected values taken from each prompt's header; when a prompt is executed, replace them with what was actually produced and set the status.

This is what proves, to the instructor and to the team later, that every piece of code was born from a traceable requirement and not from an agent's assumption.

## How to update a row

1. Confirm the prompt's `Blocked by:` prompts are done.
2. Send the prompt to the agent and audit the diff (the auditor role: don't trust the agent's text summary).
3. Run the described tests and manual checks.
4. Replace the expected artifacts and evidence with the real ones and change the status to `done` with the commit or pull request reference. Owners and reassignments live in `prompts/README.md`.
